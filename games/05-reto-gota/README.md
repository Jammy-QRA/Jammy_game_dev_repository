# 💧 Reto Gota

## 🎮 Descripción del juego

**Reto Gota** es un videojuego educativo e interactivo enfocado en la importancia del cuidado del agua.

El jugador debe superar diferentes desafíos relacionados con el uso responsable de este recurso, tomando decisiones y completando objetivos para avanzar en el juego.

El proyecto busca combinar entretenimiento y aprendizaje mediante una experiencia sencilla que promueve la conciencia ambiental.

---

## 🕹️ Cómo jugar

1. Inicia el juego desde la pantalla principal.
2. Observa el reto o situación presentada.
3. Interactúa con los elementos disponibles.
4. Completa correctamente los desafíos relacionados con el cuidado del agua.
5. Avanza hasta conseguir el objetivo final.
